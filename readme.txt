====================================================
               MATH BUDDY INSTALLATION
====================================================

To install and run Math Buddy on your device:

1. Extract the contents of this ZIP file to a folder on your computer.
2. Double-click the "install.bat" file. This will install the required dependencies and automatically create a "Math Buddy" shortcut on your Desktop.
3. To use the app at any time, simply double-click the "Math Buddy" shortcut on your Desktop! This will automatically start the server and open the app in your browser.
